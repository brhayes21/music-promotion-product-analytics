# Product Recommendations

These recommendations are based on a **synthetic portfolio dataset** and demonstrate product-analytics reasoning rather than claims about real products.

1. **Evaluate campaign quality beyond reach.** Pair impressions with conversion, saves, playlist adds, repeat listening, and skips.
2. **Use audience-specific success metrics.** Discovery-oriented campaigns should not necessarily use the same benchmarks as fan-engagement campaigns.
3. **Investigate high-reach / low-conversion campaigns.** These are strong candidates for targeting, creative, or placement diagnostics.
4. **Separate acquisition from retention outcomes.** Initial conversion and repeat behavior capture different stages of the listener journey.
5. **Validate decisions experimentally.** Follow observational analysis with controlled tests using pre-defined primary and guardrail metrics.
